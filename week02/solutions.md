# Week 2 思考题与证明题解答

## 第 1 题：代数证明题

**题目**：在一元线性回归中，证明残差之和必然等于零（∑eᵢ = 0），且残差与自变量乘积之和也必然等于零（∑xᵢeᵢ = 0）。

### 预备记号

一元线性回归模型：

```
ŷᵢ = β̂₀ + β̂₁xᵢ ,  残差 eᵢ = yᵢ − ŷᵢ
```

OLS 估计量为：

```
β̂₁ = Sxy / Sxx = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²
β̂₀ = ȳ − β̂₁x̄
```

### 第一部分：证明 Σeᵢ = 0

将 β̂₀ = ȳ − β̂₁x̄ 代入残差和：

```
Σeᵢ = Σ(yᵢ − β̂₀ − β̂₁xᵢ)
    = Σyᵢ − nβ̂₀ − β̂₁Σxᵢ
    = nȳ − n(ȳ − β̂₁x̄) − β̂₁·n x̄
    = nȳ − nȳ + nβ̂₁x̄ − nβ̂₁x̄
    = 0                                          ∎
```

### 第二部分：证明 Σxᵢeᵢ = 0

**关键技巧：将残差中心化变形。** 把 β̂₀ = ȳ − β̂₁x̄ 代入残差定义：

```
eᵢ = yᵢ − β̂₀ − β̂₁xᵢ
   = yᵢ − ȳ + β̂₁x̄ − β̂₁xᵢ
   = (yᵢ − ȳ) − β̂₁(xᵢ − x̄)
```

然后拆项并利用第一部分的结论：

```
Σxᵢeᵢ = Σ(xᵢ − x̄)eᵢ + x̄·Σeᵢ
      = Σ(xᵢ − x̄)eᵢ                    （由第一部分 Σeᵢ = 0）

      = Σ(xᵢ−x̄)[(yᵢ−ȳ) − β̂₁(xᵢ−x̄)]
      = Σ(xᵢ−x̄)(yᵢ−ȳ) − β̂₁Σ(xᵢ−x̄)²
      = Sxy − β̂₁·Sxx
      = Sxy − (Sxy/Sxx)·Sxx
      = 0                                          ∎
```

### 另一种理解：正则方程视角

RSS = Σeᵢ² = Σ(yᵢ − β₀ − β₁xᵢ)²，最小化 RSS 的一阶条件为：

```
∂RSS/∂β₀ = −2Σeᵢ = 0   →   Σeᵢ = 0        （截距方程）
∂RSS/∂β₁ = −2Σxᵢeᵢ = 0 →   Σxᵢeᵢ = 0      （斜率方程）
```

两个待证等式正是最小二乘法的**一阶条件（正则方程）**，所以 OLS 的解必然满足它们。这也解释了几何含义：残差向量 e 与向量 **1** 和向量 **x** 都正交。

## 第 2 题：理解思考题

**题目**：为什么在多元回归中，往模型中添加一个纯随机生成的无关特征，R² 会上升或保持不变，而调整 R²（R̄²）会下降？请用自由度与 RSS 变动解释。

### 关键定义

```
R²  = 1 − RSS/TSS                        （TSS = Σ(yᵢ−ȳ)²，只与数据有关）
R̄²  = 1 − (RSS/(n−p−1)) / (TSS/(n−1))    （p 为自变量个数）
```

### 为什么 R² 不会下降？

1. 加入新变量后，模型参数空间变大；**原模型的 OLS 解是新模型的一个可行解**。
2. OLS 在更大参数空间中重新最小化 RSS，所以新 RSS ≤ 旧 RSS（最差情况是系数取 0，RSS 不变）。
3. 纯随机特征与当前残差几乎总有微小的**偶然相关**，因此 RSS 几乎必然**严格下降**——哪怕下降量毫无实际意义。
4. TSS 与模型无关，保持不变。

结论：R² = 1 − RSS/TSS，分子不变、RSS 只降不升 → **R² 只升不降**。

### 为什么调整 R² 会下降？

加入一个变量后，R̄² 公式中同时发生两件事：

| 变化项 | 方向 | 幅度 |
|---|---|---|
| RSS | ↓ 下降 | 纯噪声带来的下降**极其微小** |
| 自由度 n−p−1 | ↓ 减少 1 | 每加一个变量固定损失 1 个自由度 |

对纯随机特征，RSS 的微小下降**不足以补偿**自由度损失，于是 RSS/(n−p−1) 上升，R̄² 下降。

### 直观总结

- R² 只回答"模型拟合得是否更近了"→ 奖励复杂度，永远偏好更多变量。
- R̄² 额外追问"这点拟合改善值不值得付出 1 个自由度"→ 惩罚复杂度。
- 等价判据：只有当新变量的 t 统计量 |t| > 1（对应 F > 1）时，R̄² 才会上升；纯噪声特征的 t 通常远小于 1，故 R̄² 下降。
